# 91taffy.com 个人网站 - 部署对照手册
# 照着做，91taffy.com 就能点亮喵！

====================================================
第一步：建 GitHub 仓库（约5分钟）
====================================================
1. 打开 https://github.com 并登录（你的账号：Donglizhen258）
2. 右上角 + 号 → New repository
3. Repository name 填：91taffy
4. 选 Public（公开）
5. 点 Create repository 创建

6. 创建后页面上点 Add file → Upload files
7. 把 D:/workbuddy/Claw/site/index.html 拖进去
   （只传 index.html 这一个文件就行，现在是 coming soon 页面）
8. 点 Commit changes 提交

====================================================
第二步：导入 Vercel 自动部署（约5分钟）
====================================================
1. 打开 https://vercel.com 点 Sign Up，用 GitHub 账号登录
2. 登录后点 Add New → Project
3. 找到刚才的 91taffy 仓库 → 点 Import
4. Vercel 会自动识别是纯静态项目，直接点 Deploy
5. 等 1-2 分钟，会给你一个 xxx.vercel.app 地址 = 部署成功
   （免费、自动、自带 HTTPS 小锁）

====================================================
第三步：绑定域名（约3分钟）
====================================================
1. 在 Vercel 项目页点顶部 Settings
2. 左边菜单选 Domains
3. 输入框填：91taffy.com → 点 Add
4. 选 DNS 验证方式
5. Vercel 会给出一串需要去域名商配的解析记录
   （照抄第四步）

====================================================
第四步：复制 Vercel 给的解析记录
====================================================
Vercel 绑定域名时会明确告诉你要加什么记录，通常是：
- A 记录：主机 @ → Vercel 的 IP（如 76.76.21.21，以页面显示为准）
- CNAME 记录：主机 www → cname.vercel-dns.com
- 具体数值以 Vercel 页面显示的为准，照抄

====================================================
第五步：去腾讯云加 DNS 解析（约5分钟）
====================================================
1. 登录腾讯云控制台 https://console.cloud.tencent.com
2. 找到域名管理 → 你的 91taffy.com → 解析设置
3. 点"添加记录"，把第四步 Vercel 给的两条照抄进去：
   - 类型 A      主机 @      记录值 = Vercel 的 IP
   - 类型 CNAME  主机 www    记录值 = cname.vercel-dns.com
4. 保存

====================================================
完成！等待生效
====================================================
- DNS 生效一般要等 5 到 30 分钟
- 生效后打开 https://91taffy.com 就能看到粉色 coming soon 页面喵！
- 以后改网站：改完 index.html → 上传到 GitHub → Vercel 自动更新
